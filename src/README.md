# Proyecto de Lógica de Programación en Java

Este proyecto contiene ejemplos prácticos de los principales temas de lógica de programación, implementados en Java.

## Temas incluidos
1. Variables
2. Tipos de Datos
3. Operadores
4. Entrada de Datos
5. Condicionales (if, else, switch)
6. Bucles (for, while, do-while)
7. Métodos Estáticos
8. Arreglos
9. Clases y Objetos
10. Herencia y Polimorfismo
